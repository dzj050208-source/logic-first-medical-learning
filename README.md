# Logic-First Medical Learning

A Codex skill for learning medical coursework and clinical-research concepts through underlying purpose, causal structure, and the distinction between visible procedures and actual scientific comparisons.

## Core approach

1. Identify the real question before defining terminology.
2. Explain what problem a method is designed to solve.
3. Separate the visible procedure from the actual scientific action.
4. Trace what is held constant, what changes, and what is compared.
5. Finish with a concise statement of the essential logic.

## Installation

```powershell
npx skills add dzj050208-source/logic-first-medical-learning --skill logic-first-medical-learning -g -y
```

## Privacy

The included learner model is a generic template. Keep personalized learning records local, and do not commit grades, medical information, identity data, or other sensitive material.
